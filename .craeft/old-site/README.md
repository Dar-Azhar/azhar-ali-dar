Craeft kept this when it imported https://www.azharali.space on 2026-11-25 (decision 149). It is not
part of the website: nothing in this folder is built or published.

  and each page with its screenshots.
- `*-desktop.jpg` (1280 px wide) and `*-phone.jpg` (390 px): how each page looked, from the top.

To make the new site look like the old one, follow the craeft-design skill (Craeft: Setup › Match the
old design gives the prompt for a coding agent).
